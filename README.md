# Number-Guessing Game

A command-line number-guessing game in Python with multiple difficulty levels, a limited number of attempts, and helpful feedback after every guess to keep the challenge fun and engaging.

## How to run

```bash
python3 guess_the_number.py
```

Requires Python 3.8+ (standard library only).

## What it teaches

Random numbers, loops, conditional logic, and user input validation.
